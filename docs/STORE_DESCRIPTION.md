# Short & long description (for GitHub / future stores)

## Short (one line)
ArrowDL — free multi-segment download manager for Windows: queue, speed limits, scheduler, local-first.

## Medium (≈400 characters)
ArrowDL is a free, open-source download manager for Windows. Accelerate HTTP(S) downloads with multi-segment transfer, organize a queue with speed limits and scheduling, and keep history on your PC — no account required. Early alpha: expect rapid updates. Not affiliated with IDM.

## Long
ArrowDL helps you download large files more reliably on everyday PCs.

**Highlights**
• Multi-segment downloading with resume  
• Queue, pause/resume, cancel  
• Global and per-download speed limits  
• Optional scheduled start  
• Categories for software, documents, and videos  
• Clear delete options (list only or delete files too)  
• Local SQLite history — privacy-friendly early builds  

**Perfect for** installers, documents, media files, and other direct HTTP(S) links.

**Note:** Early builds. Browser link catch and advanced video detection are planned for a later version. Always download files you have the right to access, and scan executables with antivirus software.
