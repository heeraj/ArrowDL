# ArrowDL 0.1.0-alpha — First public early build

Thank you for trying ArrowDL!

## What’s included
- Desktop download manager (Python / customtkinter)
- Multi-segment downloads, queue, speed limits, scheduler
- Categories, history, delete-with-files prompt
- MIT license + Privacy Policy + Disclaimer in the repo

## Install
1. **Setup / Portable** — use the assets attached to this GitHub Release (when listed).
2. **From source** — see README (most reliable for alpha).

## SmartScreen / antivirus
Early Windows builds are **not code-signed** yet. Windows SmartScreen or AV may warn. If you cloned from https://github.com/heeraj/ArrowDL, you can run from source with Python instead.

## Known issues
- No browser capture yet
- UI polish and edge-case servers still improving
- Packaged exe may be larger than a typical native app

## Privacy
ArrowDL stores data locally only in this release. See PRIVACY.md.
